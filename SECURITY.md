# Sécurité

Une faille dans VYLIA (contournement du bouclier, fichier importé ou téléchargé qui échappe aux vérifications, fuite de
données hors du téléphone…) : écrivez à **yogistudiofr@gmail.com** plutôt que d'ouvrir une issue publique. Décrivez la
version de VYLIA, le téléphone et la version d'Android, et comment reproduire le problème. Vous recevrez une réponse
sous quelques jours ; la correction est publiée dans une nouvelle version, avec votre nom si vous le souhaitez.

Seule la dernière version publiée sur la [page des versions](https://github.com/GuillaumeCHR/VYLIA/releases/latest) est
corrigée. Ce que VYLIA vérifie dans les données externes est décrit dans
[`docs/security/donnees-externes.md`](docs/security/donnees-externes.md).

---

To report a vulnerability, email **yogistudiofr@gmail.com** instead of opening a public issue, with the VYLIA version,
the phone and Android version, and steps to reproduce. Only the latest release is supported.
